# Changelog

All notable changes to Agentic SDD Governance (ASG) are documented here.

## [1.0.0] - 2026-08-25

Initial canonical release.

### Added

- Agentic SDD Governance — ASG naming and project-agnostic governance model.
- Lite / Standard / Strict governance profiles.
- Product Truth → Architecture → Acceptance → ACTIVE_WORK → Work Order → Implementation → Evidence → Reviewer workflow.
- Explicit stage authorization and prohibition on agent self-acceptance.
- Requirement-bound acceptance evidence and requirement hashing policy.
- Source/evidence/report traceability requirements.
- Real-browser evidence policy for user-facing behavior.
- Additive extensibility review principles.
- External/paid side-effect authorization defaults.
- Canonical templates for ACTIVE_WORK, Work Order, Reviewer Decision, ADR, Work Ledger, and Acceptance Contract.
- Canonical Codex / implementation-agent startup command.
- Unified Media Studio recorded as the first ASG Strict adopter.

### Release Note

The repository content marked `1.0.0` is the canonical ASG v1.0.0 source. A Git tag/release `v1.0.0` should point to the canonical release commit.
